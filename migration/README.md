## Conventions for porting
- Layouts: `src/layouts/<jekyll-layout-name>.astro` (props: `{ page }`). They wrap `default.astro`, use `<Content page={page} />` for `{{ content }}`.
- Bodies: `src/page-bodies/<page.id>.astro` (props: `{ page }`), where `page.id` = URL path without `.html`/trailing slash (`about/index`, `stereo-equipment-and-components-we-buy/krell/cd-1`).
- Includes: `src/components/<PascalName>.astro`; Jekyll `include.x` params become Astro props. Site data: `src/lib/site.ts` (`site`, `data`, `pages`, `posts`, `allPages`); filter helpers: `src/lib/liquid.ts`.
- Original templates: `../stereobuyers/_layouts`, `../stereobuyers/_includes`.
- Verify: `npx astro build --outDir /tmp/dist-<you> && node scripts/compare.mjs --dist /tmp/dist-<you> <url-prefix>...`
